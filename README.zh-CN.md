## 系统要求

- **Apple Silicon** Mac（M1 或更新机型）。
- **macOS 14 或更高版本**。
- 可正常运行的 macOS 原神环境，二者之一：
  - **CrossOver 25（原神定制版）**，在容器中安装原神并使用 D3DMetal 渲染；或
  - **[YAAgl OS](https://github.com/yaagl/yet-another-anime-game-launcher)**（上游移植的主要适配目标）。
- 游戏窗口设为 **1920 × 1080**、16:9、默认亮度。不建议开启 HDR、画面滤镜或改变截图颜色的后处理。
- Release 已内置自提供的 BetterGI Core，无需另装 .NET。

## 安装

1. 下载并解压 `Bettergi-pro-mac-v<版本>-arm64.zip`。
2. 把整个 `bettergi-mac` 文件夹放到方便的位置 —— 启动脚本依赖相对路径，请保持文件夹结构完整。
3. 首次打开时按提示授予 **屏幕录制** 和 **辅助功能（无障碍）** 权限（见下方 macOS 权限）。
4. 授予「屏幕录制」后，**完全退出 BetterGI 再重新启动** —— macOS 需要重启应用才能生效。
5. 若 macOS 拦截打开（「无法验证开发者」），前往 **系统设置 → 隐私与安全性**，确认文件来自本仓库 Releases 后选择 **仍要打开**；也可右键应用选择「打开」。

> 请保持 `bettergi-mac` 文件夹与同级的 `原神-mac` 文件夹在同一层。游戏未运行时，启动脚本会去找 `../原神-mac/① 启动原神.command` 自动拉起游戏。

## 启动前：游戏窗口设置（重要）

识别准确率取决于正确的游戏窗口尺寸。运行 BetterGI 前：

1. 把原神设为 **1920 × 1080 窗口化** 模式。这是分辨率识别补丁正常工作的前提。
2. 保持 **16:9** 与 **默认亮度**；不要开启 HDR 或改变颜色的滤镜。
3. 进入 **大世界** 并保持游戏窗口可见。登录界面、启动器窗口不能作为自动化目标。

未设置为 1920 × 1080 是白条 / 裁剪识别错误最常见的原因。

## 使用步骤

1. 双击 `原神-mac/① 启动原神.command`，等待进入大世界。
2. 双击 `bettergi-mac/② 启动BetterGI.command`，脚本会：检测游戏是否运行（未运行则尝试启动）、退出已有的 BetterGI 进程、以 `DYLD_INSERT_LIBRARIES` 注入两个补丁后直接启动应用（使用 `exec`，**不是** `open -a`，否则注入会失效）、校验补丁是否生效。
3. 看到两行确认信息 —— `✅ 白条/分辨率补丁(v7) 已生效` 与 `✅ 一条龙保存修复 已注入` —— 后再使用自动化功能。
4. 在 BetterGI 窗口中正常选择并执行任务。

完整的补丁说明、编译方法、已知限制与常见问题见英文版 [README.md](README.md)。
